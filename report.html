00

执行摘要

官网升级的本质，不是「改版面」，而是把百奥几何已经建立的技术领先性，翻译成五类访客（B 端客户 / C 端科研用户 / 媒体 / 投资人 / 行业竞品）都能感知到的权威叙事与可信证据。

为什么是现在（Why now）

GeoFlow V4 / GeoFlow Code 将于 2026 年 8 月底发布——公开抗原-抗体结构预测基准合格率约 70%（上一代约 45–50%，市场主流 65–68%）、命中率 20%→30%、亲和力进入 pM 量级、覆盖蛋白/抗体/环肽三模态。这是官网有史以来最大的一次自然流量窗口，也是重构信息架构的最佳时机。

核心判断（Key verdict）

现有官网是一个「合格的初创公司展示页」，但与百奥几何当前的行业位置（图灵奖得主顾问、NVIDIA 联合研究、Pre-A 顶级机构阵容、平台化产品 prot.design）严重不匹配。官网已落后于公司实力两个身位。

升级总策略一句话：以「模型代际发布线」为内容主轴（对标 Latent Labs / EvolutionaryScale），以「干湿闭环证据」为信任主轴（对标 Insilico / Nabla），以「prot.design 平台入口」为转化主轴（对标 Tamarind / NeuroSnap），三大主轴汇聚于一个信息架构——让访客在 3 屏之内确认「这家公司是生成式蛋白质设计的第一梯队」。

1.2 升级的三重驱动

① 发布窗口驱动

V4 是「基石性能 + 概念创新（GeoFlow Code 编程语言）+ 落地验证（pM / 三模态）」三位一体的发布。官网必须成为发布的第一承接阵地（公众号 → 官网 → 技术报告 PDF → 平台试用 → BD 线索）。

② 公司阶段驱动

Pre-A 之后，公司进入「被严肃尽调」阶段：药企 BD、投资机构、媒体在接触前都会先看官网。官网内容的厚度与口径严谨度直接影响尽调第一印象。

③ 竞争格局驱动

2025–2026 国际同行密集发布（Chai-2、Latent-X、JAM-2、ESM3 后续），国内字节 Anew、分子之心等加速。而多个竞品官网处于缺位/停滞状态（详见 4.5），官网质量本身就是竞争信号。

基于对现行官网的逐页走查。总体结论：现有官网处于「初创公司展示页」阶段，信息架构、证据密度、转化设计均无法匹配公司当前的行业位置与发布节奏。

4.6 对标共性公式与空白机会

一流官网的共性公式

代际发布线（事件化）× 证据密度（指标+案例+论文）× 权威堆栈（人+机构+资本）× 明确转化（平台/BD 双轨）× 口径严谨（脚注与免责声明）。五项全占者，国际上不超过 5 家，国内为 0。

百奥几何的空白机会

① 国内尚无「模型发布线」运营的蛋白设计公司；② 唯一拥有「自家可用平台 prot.design」的头部模型公司；③ 合成生物赛道无 AI 原生叙事；④ 字节 Anew 官网缺位期。——五项公式全部落地即可成为国内第一、国际第一梯队的官网。

首页展示逻辑：逐屏拆解与设计理由

关于首页，大家最常问两个问题——「首页为什么这么长？」「为什么有些内容和子页面重复？」本章一次讲透：首页不是一篇被「读完」的文章，而是一张被「扫读 + 跳入」的全站微缩地图，并逐屏给出「展示什么、为什么、通向哪里」。

8.1 首页的角色：微缩地图与信任漏斗

为什么允许「长」？—— 因为滚动比点击便宜

可用性研究的基本结论：每多一次点击，流失约一半访客；而滚动几乎零成本。首页把九类访客最关心的问题（技术牛不牛 / 做过没有 / 谁背书 / 怎么合作 / 还在不在活跃）按优先级纵向铺开，每屏只回答一个问题，并给出一个跳入深页的出口。访客不需要读完全部 12 屏——他在自己关心的那一屏停下来，点进去，首页的任务就完成了。

为什么和子页「重复」？—— 金字塔原理的摘要层

首页与子页的关系是「摘要与正文」：首页用 3 行字讲干湿闭环，技术页用一整页证明它；首页放 1 张基准图，科学页放完整报告。重复的不是内容，是路标——这正是 Google、Insilico 等大站通用的轮毂式（Hub-and-Spoke）内容模型：首页是毂，子页是辐，毂上必须有每一根辐的入口，否则那一类访客就流失了。

信任漏斗总逻辑：先给结论（证据前置）→ 再给方法（闭环可信）→ 再给创新（Code 制高点）→ 再给证据（案例与背书）→ 最后给出口（每 2–3 屏一个 CTA）。明暗场景交替控制阅读节奏，12 屏是上限而非常态——发布期后可根据数据收缩到 8–9 屏。

8.3 节奏纪律：长而不累的三条硬规则

一屏一事

每屏只回答一个问题，标题即结论；任何一屏不得同时承担两个信息任务——这是「长而不乱」的关键。

明暗交替

浅底（阅读）与暗场（聚焦）交替出现：05–06 屏的暗色发布区既是内容高点，也是视觉节奏的重启。

出口密度

每 2–3 屏必有一个明确的跳转出口（按钮或箭头链），访客在任何一屏停下来都能继续深入——首页从不把人读到底。

8.4 链接逻辑：同向是设计，落点必须不同

全站审计后，我们把「多个入口指向同一页面」分成两类：刻意的转化设计与必须修正的偷懒。判断标准只有一条——同一个页面目标，不同入口必须落到不同位置（锚点）或承担不同角色；完全同向同点、且无任何角色差异的，就是偷懒。

刻意同向（保留，共三类）

① 常驻北极星 CTA：导航「体验 GeoFlow」与各页情境按钮同指 prot.design——访客在任何页面、任何滚动深度都能一键到达转化终点，这是 SaaS 官网通行做法；② 页脚站点地图：页脚重复导航全部条目，是「最后一屏的目录」，全球官网惯例；③ 发布期公告条：全站顶部横幅同指 GeoFlow Code 专题页，是 V4 发布窗口的脉冲式引流，发布期结束后一键撤下。

指向同一页面的多个入口，必须各自带锚点、落到该页与入口语义对应的位置：新闻卡→对应新闻条目；案例卡→对应案例区；岗位「申请」→该岗位的投递动作。访客每点一次，都觉得「这一步带我到了更具体的地方」——信任感就是这样累积的。
